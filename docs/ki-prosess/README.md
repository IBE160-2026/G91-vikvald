# KI-prosess

Denne mappen viser hvordan KI er brukt og styrt i prosjektet, koblet til konkrete endringer i repoet.

| Fil | Innhold |
|---|---|
| [prompts.md](prompts.md) | Viktige prompts, hva de førte til, og hvilken commit de er knyttet til |
| [korrigeringer.md](korrigeringer.md) | KI-forslag som er avvist eller rettet, og feil KI gjorde |
| [beslutninger.md](beslutninger.md) | Viktige valg med begrunnelse |
| [refleksjoner.md](refleksjoner.md) | Egne svar på refleksjonsspørsmål om KI-bruken, grunnlag for rapporten |

**Slik brukes mappen:** Filene oppdateres i samme økt som endringen skjer. Oppsummeringer av øktene ligger i `.logs/`, og åpne punkter ligger i GitHub Issues og `issues.md`.

**Hva som ikke lagres:** Fullstendige KI-økter legges ikke i repoet, fordi det er offentlig og øktene kan inneholde personopplysninger og tekniske detaljer om kontoer. Prompts er derfor valgt ut. De gjengis ordrett, men kan være forkortet med «…».
