Fortsette den autonome kjøringen etter `_bmad-output/implementation-artifacts/autonom-kjoring.md` (/goal), fra story 5.5 og ut sprinten. Orkestratoren skriver ingen kode. Den starter én subagent per story, sjekker flettingen og testene på main, og lager gjennomgangsissuer etter hver epic.

### Plan
- Per story: start en subagent med story-prompten, sjekk at PR-en er flettet og at storien står som `done`, kjør `uv run pytest` og `npm run test` på main, rydd i Docker og sjekk disken.
- Per epic: start en subagent som utvider brukerreisetestene, og lag issuet «Gjennomgang av epic N».
- Til slutt: `sprint_plan.py status`, testene på main og `npx playwright test e2e/brukerreiser` mot `docker compose up`.
