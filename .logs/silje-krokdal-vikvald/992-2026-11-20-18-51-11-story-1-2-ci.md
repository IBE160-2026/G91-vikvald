# Story 1.2: CI

## 2026-11-20 kl. 18:51 — Silje Krokdal Vikvald

### Oppgave
Bygge story 1.2 «Kjør testene automatisk ved hver pull request» i den autonome kjøringen: CI i GitHub Actions som kjører backend- og frontendtestene ved hver pull request mot `main`, slik at sensor kan se at det som flettes, er testet.

### Plan
- Branch `story/1-2`, så `bmad-build-auto`: spesifikasjon, implementering i subagent, gjennomgang med fire gjennomgåere, rettinger.
- Kjøre pytest, Vitest og Playwright lokalt, og prøve arbeidsflyten på GitHub både grønn og rød.
- Spesifikasjon: [spec-1-2](../../_bmad-output/implementation-artifacts/spec-1-2-kjor-testene-automatisk-ved-hver-pull-request.md).

### Resultat
- `.github/workflows/ci.yml`: én jobb `tests` (vises som «CI / tests») ved pull request mot `main`: `uv sync --locked` + `uv run pytest` i `backend/`, `npm ci` + `npm run test` i `frontend/`. Ingen hemmeligheter, ingen database, ikke Playwright, `LLM_PROVIDER=mock`, tidsgrense 15 min. Frontendtestene kjører selv om backend feiler. Commit `0774f9e`, `be96487`, `57545f8`.
- `frontend/lib/ci-workflow.test.ts`: sju `AR-20`-tester som sjekker arbeidsflyten. README forklarer at pytest og Vitest kjører automatisk og at Playwright kjøres lokalt (`5036185`).
- Gjennomgang: 19 funn, 7 rettet, 12 avvist med begrunnelse i spesifikasjonen.
- Tester: `uv run pytest` 4 passed, `npm run test` 10 passed, `npx playwright test` 2 passed mot `docker compose up --build`. På GitHub (PR #38): grønn kjøring, rød kjøring med en test som feilet med vilje (tilbakestilt i `aaab483`), og grønn igjen med `setup-uv@v7`.
- Ingen skjermbilder: storien endrer ingenting brukeren ser.
- Sprint-status: story 1.2 `done`, epic 1 `in-progress`. KI-spor oppdatert (`5e83228`). Issue #39 og #40 laget med etiketten `kanttilfelle`.
- Et feilskrevet `git revert` førte til en lokal feil-commit som ble avvist ved push. Committene ble bygd på nytt fra den pushede branchen (lokal branch `story/1-2-arbeid`); den gamle lokale `story/1-2` har feil-committene og kan slettes.

### Åpne punkter
- Avgjør om en pull request med røde tester skal sperres mot fletting (grenbeskyttelse). Krever admin-tilgang til repoet (#39).
- Avgjør om CI også skal kjøre etter fletting til `main` (#40).
- `LLM_PROVIDER=mock` i CI virker først når story 1.3 leser innstillingen.
